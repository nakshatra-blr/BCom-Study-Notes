## 📖 Financial Accounting

### Key Topics

| Topic | Key Concepts |
|-------|-------------|
| **Double Entry System** | Every debit has a credit, Journal entries, Ledger posting |
| **Final Accounts** | Trading A/c, P&L A/c, Balance Sheet |
| **Depreciation** | SLM, WDV, methods comparison |
| **Bank Reconciliation** | BRS preparation, causes of difference |
| **Rectification of Errors** | One-sided, two-sided, suspense account |
| **Partnership Accounts** | Admission, retirement, dissolution |
| **Company Accounts** | Issue of shares, debentures, buyback |

### Golden Rules of Accounting
```
Personal Account:  Debit the Receiver, Credit the Giver
Real Account:      Debit what Comes In, Credit what Goes Out
Nominal Account:   Debit all Expenses/Losses, Credit all Incomes/Gains
```

## 💰 Cost Accounting

### Cost Classification

| Basis | Types |
|-------|-------|
| **By Nature** | Material, Labour, Overheads |
| **By Function** | Production, Admin, Selling, Distribution |
| **By Behaviour** | Fixed, Variable, Semi-variable |
| **By Control** | Controllable, Uncontrollable |

### Important Formulas

```
Prime Cost = Direct Material + Direct Labour + Direct Expenses
Factory Cost = Prime Cost + Factory Overheads
Cost of Production = Factory Cost + Office Overheads
Total Cost = Cost of Production + Selling & Distribution Overheads
Profit = Sales - Total Cost
```

### Break-Even Analysis
```
BEP (Units) = Fixed Cost / Contribution per Unit
BEP (Sales) = Fixed Cost / P/V Ratio
P/V Ratio = (Contribution / Sales) × 100
Margin of Safety = Actual Sales - BEP Sales
```

## 📈 Financial Management

### Time Value of Money
```
FV = PV × (1 + r)^n
PV = FV / (1 + r)^n
EMI = P × r × (1+r)^n / [(1+r)^n - 1]
```

### Capital Budgeting Methods
1. **NPV** (Net Present Value) — Accept if NPV > 0
2. **IRR** (Internal Rate of Return) — Accept if IRR > Cost of Capital
3. **Payback Period** — Shorter is better
4. **Profitability Index** — Accept if PI > 1

### Capital Structure Theories
- Net Income Approach
- Net Operating Income Approach
- Modigliani-Miller (with/without tax)
- Trade-off Theory
- Pecking Order Theory
